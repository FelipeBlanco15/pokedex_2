PokéDex Base Portfólio

Guia de Arquitetura & Tecnologias Utilizadas

Este documento detalha tudo o que foi utilizado neste projeto base, como os componentes foram estruturados, como a PokéAPI foi consumida via requisições assíncronas.

1. HTML5 Semântico

O que foi usado: Tags semânticas como <header>, <nav>, <main>, <section> e <dialog>.

Como foi usado: Garante acessibilidade (screen readers), SEO estruturado e organização modular das seções da Pokédex e do guia didático.

2. CSS3 Moderno

O que foi usado: Variáveis CSS (Custom Properties), Flexbox, CSS Grid responsivo, Glassmorphic UI e animações @keyframes.

Como foi usado: Definimos temas de cores por tipo de Pokémon (ex: Fogo = Laranja/Vermelho, Água = Azul) e sombras com profundidade sem utilizar frameworks externos.

3. JavaScript ES6+ & Fetch API

O que foi usado: async/await, fetch(), Promise.all(), Arrow Functions e Manipulação dinâmica da DOM.

Como foi usado: Fazemos requisições para a REST API pública https://pokeapi.co/api/v2/pokemon e parseamos as respostas JSON para criar cards dinâmicos na tela.

4. REST API (PokéAPI)

Endpoints Principais:

  • GET /pokemon?limit=24&offset=0: Lista inicial com nomes e URLs de detalhes.
  • GET /pokemon/{id_ou_nome}: Detalhes do Pokémon (estatísticas, tipos, peso, altura e artes em HD).

🎯 Desafios Marcados no Código para o Seu Portfólio

O código JavaScript (script.js) e CSS possuem comentários detalhados marcando desafios guiados para você implementar e completar o projeto:

Fácil

Desafio 1: Filtro Dinâmico por Tipo

No script.js, implemente a lógica na função handleTypeFilter() para filtrar a lista atual de Pokémon com base na opção selecionada no seletor de tipos.

Médio

Desafio 2: Sistema de Favoritos com LocalStorage

Crie as funções toggleFavorite(id) e loadFavorites() para permitir que o usuário marque Pokémons com um coração e salve no navegador.

Médio

Desafio 3: Botão Alternador de Sprite Shiny

No modal de detalhes, adicione um botão para trocar a imagem normal (art oficial) pela versão Shiny retornada pela API (sprites.front_shiny).

Avançado

Desafio 4: Reprodutor de Áudio (Cries dos Pokémon)

A PokéAPI fornece um áudio com o grito de cada Pokémon em cries.latest. Adicione um botão de alto-falante no modal para tocar o som!
